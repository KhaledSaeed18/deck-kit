Architecture

Three layers. Tests keep them apart.

Slides

src/slides/
src/deck.ts
  • one HTML partial per slide
  • build steps
  • speaker notes and Q&A
  • inline SVG diagrams
  • profiles and timings
changes every talkContent and semantic markup only. No styles.

Theme

src/theme/**
  • colour tokens
  • bundled fonts
  • type scale
  • layouts per slide type
  • diagram classes
  • presenter look
changes every designEvery visual value lives here, as a token.

Engine

src/engine/**
  • keys and clicker
  • hash router
  • presenter sync
  • overview
  • print
  • slide lint
never changesNo colours, no fonts. Browser tests guard it.
