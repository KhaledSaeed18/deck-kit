Script

Presentation clickers send PageUp and PageDown, so any clicker works.

Rows reveal one by one. Hidden rows keep their space, so the table never jumps.

Type a slide number, then Enter. G shows the jump chip first.

P opens this presenter window. Navigating in either window moves both.

O shows every slide as a grid. B blacks out the audience screen when you want the room's attention.
