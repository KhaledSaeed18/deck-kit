Script

When people imagine code breaking they picture the British code breakers attacking Enigma: brilliant mathematicians and room-sized machines. That is only one door.

Classical cryptanalysis attacks the maths: analytical attacks like the one we just did, or brute force.

Implementation attacks measure the device instead. The power a chip draws, its electromagnetic radiation or how long it takes can reveal the key. These matter most when the attacker can hold the device, like a smart card.

Social engineering skips the technology. "Hello, this is IT, we need your password for an update." It still works far too often.

An attacker always looks for the weakest link. A strong cipher is necessary, and it is not enough.
