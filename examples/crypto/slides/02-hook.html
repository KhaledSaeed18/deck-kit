This is example 1.2 from the book. It looks like noise. It is a normal English sentence.

Each letter was replaced by another one using a secret table. There are 26 factorial possible tables, about 2 to the power 88. Testing a billion a second, trying them all would take about 13 billion years, roughly the age of the universe.

So is it secure? Hold that thought. In about five minutes we will read it without ever finding the key by search.
