Wi-Fi 6: from faster to smarter

OFDM vs OFDMA

Orthogonal Frequency-Division Multiplexing; OFDMA adds Multiple Access

  • TWT

    Target Wake Time

  • BSS coloring

    BSS = Basic Service Set (one Wi-Fi network)

Script

Wi-Fi 6 is where the goal changed: from faster to smarter, so a busy network works well.

OFDM gives the whole channel to one user per transmission: one truck per delivery, so even a tiny message uses a whole transmission.

OFDMA splits the channel so many users share one transmission: one truck carries packages for several users at once. That helps a lot when there are many small messages: phones, chat, smart devices.

TWT, Target Wake Time: devices sleep until their scheduled time to wake up, which saves battery.

BSS coloring (a BSS is one Wi-Fi network: a router and its devices): your network can talk over a faint neighbour on the same channel instead of always waiting.

Wi-Fi 6E is the same technology plus the new 6 GHz band, where the country allows it.

Acronyms

  • OFDMA: Orthogonal Frequency-Division Multiple Access
  • TWT: Target Wake Time
  • BSS: Basic Service Set (one router and its devices)

If asked

  • Wi-Fi 6 vs 6E? Same technology; 6E adds the 6 GHz band, subject to national regulation.
  • OFDMA vs MU-MIMO? OFDMA gives users different slices of the channel at once; MU-MIMO serves users on the same frequency using different antennas. Wi-Fi 6 can use both.
More detail and sources

More questions

  • How many users share one OFDMA transmission? With the smallest resource unit (26 tones), up to 9 stations share a 20 MHz channel.
  • Are TWT and BSS coloring new in Wi-Fi 6? Both first appeared in 802.11ah (Wi-Fi HaLow, for IoT); 802.11ax adapted them for dense networks.

Local context

Lebanon has not opened 6 GHz. TRA consulted in April 2026 on the lower part of the band, 5925 to 6425 MHz, for licence-free indoor use (the upper part, 6425 to 7125 MHz, is still undecided between Wi-Fi and mobile networks) and comments closed on 28 August 2026, with no decision as of October 2026. Here, Wi-Fi 6E and 7 run on 2.4 and 5 GHz at up to 160 MHz.
