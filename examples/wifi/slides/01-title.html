Script

Hello everyone. I'll start from Table 1.5 in Lecture 1 and ask a simple question: what does it look like today?

Wireless networks are grouped by how far they reach. Inside that map, Wi-Fi is the one we all use most. Each Wi-Fi generation fixed the main problem of the one before: first speed, then crowding, then delay, and now, with Wi-Fi 8, reliability instead of speed.
