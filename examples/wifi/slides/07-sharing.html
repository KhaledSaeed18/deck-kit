Sharing the air: why Wi-Fi takes turns

  1. Listen
  2. Wait random backoff
  3. Transmit
  4. ACK

Script

Wi-Fi devices share one channel, and a radio can't send and listen at the same time. That's half-duplex, like a walkie-talkie in Lecture 1. So they take turns.

Listen: is anyone else talking?

Wait a random moment, so two devices don't start at the same time.

Transmit: send the data.

ACK: the receiver says "got it". No ACK means something collided, so the sender tries again.

This is called CSMA/CA: avoid collisions, because a radio can't hear one while it is sending.

Now the story of Wi-Fi itself, generation by generation.

Acronyms

  • CSMA/CA: Carrier Sense Multiple Access with Collision Avoidance
  • ACK: Acknowledgement
  • CSMA/CD: Carrier Sense Multiple Access with Collision Detection (old shared-cable Ethernet)

If asked

  • Is Wi-Fi full-duplex? No, half-duplex. Full-duplex Wi-Fi is a research topic because of self-interference (Lecture 1, slide 7: the full-duplex figure's "Self-Interference" label).
More detail and sources

More questions

  • How hard is full-duplex? A Wi-Fi radio transmits at about 20 dBm and listens near -90 dBm, so it must cancel about 110 dB of its own signal. Prototypes exist; no 802.11 amendment does it.
  • Is RTS/CTS always on? No. It is optional and the usual default threshold effectively turns it off, because it adds overhead.

Nuances

  • CSMA/CD was only classic shared-cable Ethernet; modern switched Ethernet does not need it.
  • Trap: Lecture 1, slide 8 calls TDD a form of full-duplex. Wi-Fi also takes turns in time, but at the radio it never sends and receives at the same instant, so it is half-duplex.
